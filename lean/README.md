# Lean 4 + Mathlib proof

`BM.banachMazur_diam_le` in [`BMLean/Final.lean`](BMLean/Final.lean) proves that d_BM(K, L) ≤ 11/5 for all
planar convex bodies K, L. There is no `sorry`. The definitions it uses are in
[`BMLean/Statement.lean`](BMLean/Statement.lean).

- `BMLean/Main.lean`: the paper's argument, `BM.diam_le`. It assumes Besicovitch's inscribed
  affine-regular hexagon lemma as the hypothesis `BM.Besicovitch`.
- `BMLean/Besicovitch.lean` and `BMLean/Besicovitch/`: a proof of that lemma, `BM.besicovitch`.
- Axioms: `propext`, `Classical.choice` and `Quot.sound`, plus 94 `native_decide` runs that check the
  certificate. Those runs make the Lean compiler part of the trusted base.

```bash
lake exe cache get   # Mathlib cache
lake build           # the whole proof, including the certificate check (about 2 min on 8 cores)
```

`BMLean/Data/` holds the certificate `../search_result.jsonl.gz` as Lean data. It was
generated by `python3 scripts/gen.py ../search_result.jsonl.gz BMLean/Data 100 24 && python3 scripts/genrun.py BMLean`.
The generator does not need to be trusted: the Lean checks are statements about whatever data it produced.
